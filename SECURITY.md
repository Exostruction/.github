# Security Policy

## Reporting a vulnerability

Please do **not** report security vulnerabilities through public issues.

- Use the **Security** tab of the affected repository and click **Report a vulnerability** (private reporting through GitHub).
- Alternatively, email [hello@exostruction.com](mailto:hello@exostruction.com) with the subject `Security`.

Please include the affected repository, the version, a short description, and steps to reproduce if possible.

We usually respond within 3 business days and keep you updated on the progress of the fix. Please give us a reasonable chance to fix the issue before disclosing details publicly.
