# Contributing

Thanks for your interest in contributing to a project by Exostruction.

## Quick workflow

1. For larger changes, open an issue first so we can align on the approach.
2. Fork the repository and work in a topic branch (`feat/...` or `fix/...`).
3. Keep changes small and focused, one pull request per topic.
4. Describe in the pull request what changes and why.
5. Make sure tests and linters pass, where the repository has them.

## Commit messages

We use [Conventional Commits](https://www.conventionalcommits.org/en/v1.0.0/), for example `fix: handle empty password` or `feat: add CSV export`.

## Security

Please do not report security issues publicly, see [SECURITY.md](./SECURITY.md).
